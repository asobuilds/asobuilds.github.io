Featured Project

⭐ Featured Project

Plant Assistant

An AI-powered platform that helps farmers identify plants, get season-specific care advice, and access pesticide recommendations. The goal is to democratize agricultural knowledge for small-scale farmers.

The Challenge: Farmers often lack access to quick, reliable plant information. The solution needed to be simple, visual (using image recognition), and work in areas with limited connectivity.

The Solution: A Progressive Web App (PWA) using Python and a fine-tuned ML model for plant identification, with a geolocation-based advisory system.
